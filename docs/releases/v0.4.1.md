# Invoice Maker v0.4.1

Each completed inspection can now be billed only once, while no-shows can be rescheduled as often as needed.

## What's changed

### Each completed inspection is billed once

- Each VIN (last 8 characters) and each inspection # can be on only one **completed** row, across the invoice you're working on and all your locked invoices, in any year. Cancelled invoices don't count.
- If one repeats, the row shows a note naming where it was already billed, and **Lock & Save** stays off until you fix it. Your draft still saves while you sort it out.
- **Lock & Save checks your locked invoices again as it locks.** If the VIN or inspection # was billed elsewhere in the meantime, it says where and leaves the invoice unlocked.
- **Duplicate** still pre-fills a new invoice from an old one. Change the VIN and inspection # on its completed rows before you lock it.

### No-shows can be rescheduled freely

- A no-show never uses up a VIN or inspection #. The same vehicle can be a no-show as many times as needed, on the same invoice as its completed inspection, or after it was completed. No-show rows no longer show repeat notes, and a no-show never blocks a completed inspection.

### Cancel and restore

- Cancelling an invoice frees its completed VINs and inspection #s, so you can bill them on another invoice.
- **Restore** checks them again. If one is now on another locked invoice, or appears twice on the cancelled invoice, Restore says which and leaves the invoice cancelled. Cancel the other invoice first if the cancelled one is the one to keep.

## Your existing records

- Invoices you already locked, and their PDFs, stay exactly as they are and reprint as before, even if an earlier version let a VIN or inspection # repeat. The new rule applies when you lock an invoice or restore a cancelled one.
- Unlocked drafts keep everything you typed. If a draft repeats a VIN or inspection # on a completed row, fix it before **Lock & Save**.
- **No setup needed.** This update doesn't change how your data is stored, so there is no database upgrade step.

## Install or update

**Already installed?** The app offers the update when it starts, or use **Settings → About & updates → Check for updates**.

**Windows:** download the [`.exe` installer](https://github.com/jordanvanallen/invoice-app/releases/download/v0.4.1/Invoice.Maker_0.4.1_x64-setup.exe) or the [`.msi` installer](https://github.com/jordanvanallen/invoice-app/releases/download/v0.4.1/Invoice.Maker_0.4.1_x64_en-US.msi) and run it. If Windows shows **"Windows protected your PC"**, choose **More info → Run anyway**.

**macOS (Apple silicon and Intel):** download [`Invoice.Maker_0.4.1_universal.dmg`](https://github.com/jordanvanallen/invoice-app/releases/download/v0.4.1/Invoice.Maker_0.4.1_universal.dmg). Open the DMG and drag **Invoice Maker** to **Applications**, then open it from Applications. The app is ad-hoc signed but not Apple-notarized. On first launch macOS may block it. Open **System Settings → Privacy & Security**, choose **Open Anyway** for Invoice Maker, and confirm **Open**. This is a one-time approval for this installation. See the [Mac installation guide](https://github.com/jordanvanallen/invoice-app/blob/main/USER_GUIDE.md#macos) for details.
